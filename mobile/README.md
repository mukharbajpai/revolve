# Revolve customer app

Expo SDK 58 customer application for two final outputs:

- standalone Android APK via the `apk` EAS profile;
- installable iPhone PWA via the static web export.

```powershell
npm install
npm run typecheck
npm run lint
npm run build:web
npm run preview:web
```

See the repository root `README.md` for APK and independent deployment commands. Expo Go is optional for development and is not required by either final customer output.
